# Anesthesia-Dosage-Predictor

This project predicts anesthesia sedation levels using machine learning techniques and patient health data. The system analyzes medical parameters such as age, weight, heart rate, blood pressure, and oxygen level to estimate the appropriate anesthesia dosage for patients during surgery. The project compares SVR, XGBoost, and Transformer models to identify the most accurate prediction approach.

Requirements: 

Before running the project, install the following:

Anaconda Navigator
Python 3.x

Required Python libraries:

pandas
numpy
scikit-learn
xgboost
flask
matplotlib
seaborn

How to Run the Project?

Download and install Anaconda Navigator.
Open Anaconda Navigator and launch Jupyter Notebook or VS Code.
Add the project folder into the working directory.
Open the terminal inside the project folder.
Install required libraries if not already installed

Run the application using:

python app.py

After running the command, the Flask server will start on the local host.
Open the local server link in the browser.
Enter the patient medical details in the input form.
The system will analyze the data and predict the anesthesia dosage amount.


Features:

Patient data preprocessing
Machine learning-based prediction
Real-time dosage prediction
Flask web application interface
Comparison of SVR, XGBoost, and Transformer models


Project Outcome
The project helps anesthesiologists make safer and more accurate decisions during surgical procedures by providing data-driven anesthesia dosage predictions.
